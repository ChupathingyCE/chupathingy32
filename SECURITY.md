# Security

Chupathingy32 follows the Chupathingy security policy:
[ChupathingyCE/.github SECURITY.md](https://github.com/ChupathingyCE/.github/blob/main/SECURITY.md).

To report a problem privately, open this repository's **Security** tab and
choose **Report a vulnerability**, or message a Developer privately on the
[Discord](https://discord.gg/chupathingy). Please don't post details in
public.
